RAG Pipeline

1. Chunking — RecursiveCharacterTextSplitter (512 tokens, 64 overlap)
2. Embedding — text-embedding-3-small → FAISS index
3. Retrieval — top-3 cosine-similarity chunks
4. Synthesis — GPT-4o with grounding prompt
Hallucination Guard

Answer is strictly grounded on retrieved chunks. If no chunk scores above the confidence threshold, the system responds "insufficient context" rather than hallucinating. Source citations always included.
